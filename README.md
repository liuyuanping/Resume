# 刘远平的个人简历

这是刘远平的在线简历项目。

**在线查看：** [https://liuyuanping.github.io/Resume/](https://liuyuanping.github.io/Resume/)

## 项目结构

- `index.html`：GitHub Pages 首页入口
- `resume.html`：简历页面
- `img/`：简历使用的图片资源
- `.github/workflows/static.yml`：GitHub Pages 自动部署工作流

## 本地预览

直接用浏览器打开 `index.html`，或启动一个本地静态服务器：

```bash
python3 -m http.server
```

然后访问 <http://localhost:8000/>。
